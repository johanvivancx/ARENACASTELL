Responsable y contacto

Arena Castell, a cargo de Johan Jair Oña Vivanco, atiende en Antonio José de Sucre 1880, Amaguaña, Quito, Ecuador. Para consultas o solicitudes sobre tus datos, escribe a johanviv21@gmail.com.

Qué datos tratamos y para qué

Al crear una cuenta solicitamos nombre, cédula, correo, teléfono y contraseña. La contraseña se almacena como un hash, no en texto visible. Usamos estos datos para identificar tu cuenta, gestionar reservas, inscripciones, pagos y consultas, y evitar accesos indebidos. También guardamos datos de las operaciones, como fechas, horarios, importes, estados y referencias de transferencia; no recibimos números de tarjeta.

Si inscribes un equipo o a un alumno de Súper Chaca, tratamos los datos de los participantes que ingreses, incluidos nombre, identificación y categoría. El representante debe proporcionar estos datos con autorización válida. No publicamos en la página pública los datos de identificación de alumnos y jugadores inscritos mediante estos formularios.

Quién puede acceder y dónde se alojan

El personal autorizado de Arena Castell accede a la información necesaria para administrar las actividades y revisar pagos. La aplicación y la base de datos se alojan en Render, en Estados Unidos; Cloudflare presta servicios de dominio y entrega web. Estos proveedores tratan datos para operar la página. No vendemos tus datos ni los usamos para publicidad de terceros.

Conservación y seguridad

Conservamos los datos mientras sean necesarios para mantener la cuenta, prestar los servicios solicitados, atender reclamaciones y cumplir obligaciones aplicables. Puedes pedir que revisemos o eliminemos datos que ya no sean necesarios. Usamos conexión HTTPS, acceso administrativo restringido y contraseñas almacenadas de forma no reversible. Ningún sistema puede garantizar seguridad absoluta.

Tus opciones

Puedes pedir acceso, corrección, actualización o eliminación de tus datos y consultar cómo se usan escribiendo a johanviv21@gmail.com. También puedes solicitar la revocación de un consentimiento cuando corresponda. Algunas operaciones podrían conservarse durante el plazo que exija la ley.

Si no proporcionas los datos necesarios para crear la cuenta o realizar una inscripción, no podremos completar esa operación. Puedes consultar la información pública del sitio sin registrarte.

Este aviso puede actualizarse conforme cambien los servicios. Publicaremos la versión vigente en esta página.
